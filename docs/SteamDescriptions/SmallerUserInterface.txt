Reduces size of notifications list and hides player name in the top bar.

[h2]UI Changes Made[/h2]
[table]
[tr][td]
[h3]Top Bar[/h3]
[list]
[*] Hides the player name in the top bar (including the "Achievements disabled" message after opening the Debug menu)
[*] Reduces the size of the "Menu" button. This should still fit most languages, but I suspect the text may get cut off when the game is in German.
[/list]
[/td][/tr]
[tr][td]
[h3]Top Left Actions[/h3]
This includes the player actions (edicts, Chaos marks, etc.) and unclaimed items.
[list]
[*] Reduces size to 75%
[/list]
[/td][/tr]
[tr][td]
[h3]Bottom Right UI[/h3]
This includes the notifications log, end turn button, and minimap
[list]
[*] Reduces size to ~80%
[*] Reduces the size of the notifications log to 50%
[*] Reduces the size of the End Turn button to 75%. I have Next Action bound to a convenient key, so I don't click this often.
[/list]
[/td][/tr]
[/table]

[h2]Compatibility[/h2]
Completely replaces these files:
[table]
[tr][td]
[u]Located at [b]GUI/Blueprints/World/[/b][/u]
NotificationListItem.xml
TopBar.xml
WorldHUD.xml
[/td][/tr]
[/table]
So this is not compatible with mods which edit these mods. Only one of the mods will win; usually the one on top (visually higher in the load order).

I use this with [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3395268149]Nameless[/url] to hide unit and region names.
